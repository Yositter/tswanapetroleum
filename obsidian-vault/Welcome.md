# Tswana Petroleum Vault

This folder is an Obsidian vault. An Obsidian vault is a directory of Markdown files
plus a `.obsidian` configuration folder. Open this directory in the Obsidian desktop
application and it loads as a ready configured workspace.

## Opening this vault
1. Install Obsidian on your machine. See [[Tooling Setup#1. Obsidian]].
2. Launch Obsidian.
3. Choose **Open folder as vault**.
4. Select the `obsidian-vault` directory inside this repository.

## Contents
